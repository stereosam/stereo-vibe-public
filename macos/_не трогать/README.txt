STEREO Vibe Lite — стартовый пакет вайбкодера для macOS
========================================================

КАК ЗАПУСТИТЬ
1. Распакуй архив: двойной клик по stereovibe-lite-mac.zip.
2. В распакованной папке дважды щёлкни «Запустить Vibe.command».
3. Первый раз macOS его не откроет: пакет не подписан в Apple. Что делать:
   - macOS 15 и новее: нажми «Готово», открой «Системные настройки →
     Конфиденциальность и безопасность», прокрути вниз и нажми
     «Открыть всё равно» напротив «Запустить Vibe.command», введи пароль,
     потом «Открыть»;
   - macOS 14 и старше: правый клик (или Control + клик) по файлу →
     «Открыть» → «Открыть».
   Это нужно один раз.
4. Если macOS спросит «Терминал хочет получить доступ к файлам в папке
   Загрузки» — нажми «Разрешить»: пакет лежит там и читает свою папку.
5. Отвечай на вопросы цифрами и не закрывай окно до надписи «Нажми ENTER».
   Установка может идти несколько минут — полоска внизу показывает, что всё живо.

ЕСЛИ ДВОЙНОЙ КЛИК НЕ ЗАПУСКАЕТ ФАЙЛ
(например, «недостаточно прав» после распаковки другим архиватором)
Открой Терминал (⌘ + Пробел → «Терминал»), набери bash и пробел,
перетащи в окно файл «Запустить Vibe.command» и нажми Enter.

ЧТО ДЕЛАЕТ ПАКЕТ
- проверяет место на диске и версию macOS;
- проверяет Homebrew (менеджер программ для Mac). Если его нет — спросит
  и поставит официальным установщиком с https://brew.sh. Установщик
  попросит пароль от Mac: при вводе символы не видны, это нормально;
- проверяет и ставит через Homebrew: Git, Node.js, Python, Telegram
  (только если согласишься);
- по твоему выбору ставит ИИ-агентов: Codex CLI, Claude Code, Gemini CLI,
  и приложения-ярлыки веб-версий ChatGPT и Gemini (в папку ~/Applications,
  их видно в Launchpad и Spotlight);
- проверяет, открываются ли ИИ-сервисы из твоей сети. Ничего не настраивает;
- в конце (если согласишься) заводит папку проекта ~/stereo-vibe с памятью
  агента: CLAUDE.md (правила для агента) и папка memory/, где infra_status.md
  заполнен результатами этой проверки — что стоит, каких версий, куда
  выполнен вход, какие ИИ-сервисы открываются. Без имени компьютера,
  пользователя и IP. Существующие файлы не перезаписываются: при повторном
  запуске свежая сводка ляжет рядом как infra_status.new.md.

ЧЕГО ПАКЕТ НЕ ДЕЛАЕТ
- не меняет настройки сети и системы;
- не ставит ИИ-программы без твоего выбора;
- не собирает личные данные.
Единственная правка в настройках: на Mac с чипом Apple (M1 и новее)
пакет дописывает в ~/.zprofile строку, которую советует сам установщик
Homebrew, — чтобы программы из Homebrew были видны в новых окнах Терминала.

СВЯЗЬ С ИНТЕРНЕТОМ
- программы скачивает Homebrew из официальных источников (GitHub, сайты
  производителей), Gemini CLI — npm;
- при запуске пакет узнаёт номер свежей версии
  (https://stereosam.ru/vibe-lite/version-mac.json). Если вышла новая — пишет
  об этом строкой со ссылкой на бота, где взять свежий архив. Сам ничего
  не скачивает и не обновляет;
- после проверки отправляет обезличенную сводку: версия пакета, случайный
  номер установки, версия macOS и тип процессора, статусы и версии программ
  из набора выше, открываются ли ИИ-сервисы, длительность проверки. Без имени
  пользователя и компьютера, путей, почты и ключей.
  Адрес: https://stereosam.ru/vibe-lite/report
  Не хочешь отправлять — запусти из Терминала так (путь к файлу проще всего
  получить, перетащив файл в окно Терминала):
      bash "…/Запустить Vibe.command" --no-report

ТОЛЬКО ПРОВЕРКА, БЕЗ УСТАНОВКИ
      bash "…/Запустить Vibe.command" --check

ГДЕ ЛОГ
Лог и отчёт каждой проверки лежат только на этом компьютере:
      ~/Library/Application Support/STEREO-Vibe-Lite/logs
Путь к логу пакет пишет в конце проверки.

ЧТО ЛЕЖИТ В ЭТОЙ ПАПКЕ
check-work-tools.sh — сам пакет (скрипт bash);
version.txt         — версия пакета;
templates/          — шаблоны памяти проекта (CLAUDE.md и memory/);
README.txt          — этот файл.
Папку не удаляй и не переноси: без неё «Запустить Vibe.command» не запустится.

КАК НАЧАТЬ РАБОТАТЬ ПОСЛЕ УСТАНОВКИ
Открой НОВОЕ окно Терминала (⌘ + Пробел → «Терминал»), перейди в папку
проекта (если пакет её завёл: cd ~/stereo-vibe) и набери codex, claude или
gemini. Агент сам прочитает CLAUDE.md и memory/. При первом запуске он
попросит войти в аккаунт.
