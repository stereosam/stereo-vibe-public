Старт сессии. Опциональный аргумент — номер проекта. Аргумент: $ARGUMENTS

Карта проектов (N → имя) — ЕДИНЫЙ ИСТОЧНИК: раздел «Маппинг проектов → директории» в `MEMORY.md`. Здесь НЕ дублируем — иначе разъедется. Карты нет в контексте — прочитать MEMORY.md с VPS.

Шаги:
1. **Если в "$ARGUMENTS" указан номер проекта N** (напр. `/go 2`):
   - Прочитай с VPS ДВА файла проекта (имя по маппингу MEMORY.md), одной командой:
     `ssh <user>@<your-server> "cat /path/to/memory/<name>_status.md; echo '====== BACKLOG ======'; cat /path/to/memory/<name>_backlog.md"`
   - `<name>_status.md` — впитай в контекст ЦЕЛИКОМ (что за проект, как устроен, грабли). ⚠️ Если вывод большой и ушёл в файл-персист — дочитать его частями ДО САМОГО КОНЦА, прежде чем идти дальше. Срезать нельзя.
   - КОНТРОЛЬ ЧТЕНИЯ: при показе «Активных» первой строкой указать «📖 статус: N строк, прочитан полностью» (N = реальное число строк файла). Назвать N можно только реально дочитав файл.
   - `<name>_backlog.md` — покажи раздел «Активные».
   - Жди номер задачи `N-Y`.
2. **Если аргумента нет** (просто `/go`):
   - Покажи СПИСОК ПРОЕКТОВ (номер + название) из маппинга MEMORY.md (раздел «Маппинг проектов → директории»).
   - Заодно покажи актуальные напоминания из MEMORY.md (раздел Reminders): что горит по датам.
   - Жди номер проекта → дальше как в п.1 для него (читать и status, и backlog).

Память (источник правды — VPS `/path/to/memory/`):
- Задачи проекта — `<name>_backlog.md` («Активные» + «Changelog (DONE)»).
- Сироты/кросс-проектное — `inbox.md`.
- Что проект есть/как устроен — `<name>_status.md`.
- Хроника сессий — `session_log.md` (тек. месяц) + `session_log_YYYY-MM.md` (архив).
