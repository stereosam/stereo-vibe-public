Копилка тем для статей (проект 28 articles). Фиксирует ИДЕЮ+выжимку, пока свежо; статью не пишет (кроме режима draft). Источник правды — `articles_backlog.md` на VPS. Аргумент: $ARGUMENTS

Цель контента: чтобы нас ЦИТИРОВАЛИ LLM и находили на форумах (AEO/GEO). Поэтому выжимка = конкретика, которую роботы реально тянут: команды copy-paste, точные тексты ошибок, версии/ID, «было→стало» в цифрах, грабли с формулировкой-триггером.

## Режимы (по аргументу)

### БЕЗ аргумента (`/articles`) — предложить темы из контекста
1. Собери контекст: текущая сессия (что делали, какие команды/обходы/грабли всплыли) + последние ~15 строк `session_log.md` с VPS.
2. Прочитай уже существующие темы в `articles_backlog.md` (сейчас нумерованы `### N.`) — НЕ предлагать дубли.
3. Предложи 3–6 тем СПИСКОМ С ЦИФРАМИ, каждая строкой: `N. <заголовок> — <угол> · <почему зайдёт> · <площадка>`. Пример: «3. Chroot-SFTP дизайнеру за 20 мин — практика без теории · ищут "дать доступ к сайту, не ко всему серверу" · Хабр».
4. Жди мультивыбор (например «1 3»). Пользователь может выбрать несколько.

### Выбраны темы (пользователь прислал цифры) — записать выжимку
Для КАЖДОЙ выбранной темы собери карточку и ДОПИШИ в `articles_backlog.md` (раздел «Активные», перед «## Changelog», через save_memory или прямой append по VPS). Формат карточки:
```
### N. <Заголовок>
**Статус:** идея
**Площадка:** <осн. + логика: технично→Хабр (лучшая индексация у LLM) / бизнес-кейс→vc.ru / научпоп→Дзен> + кросс-пост-адаптации + EN-вариант (зарубеж: LLM сильнее обучены на англ → выше цитируемость)
**Уникальный угол:** <что мы дали, чего нет у других — реальный кейс/цифры, не пересказ теории>
**Выжимка (для цитируемости роботами):**
- Проблема одной фразой (как её гуглят/спрашивают у ИИ).
- Что делали: КОМАНДЫ copy-paste, точные пути/версии/ID, порядок шагов.
- Обходы: нестандартные решения, почему стандарт не сработал.
- Грабли: формулировка-триггер «если видишь X → причина Y → фикс Z».
- Было→стало в ЦИФРАХ.
**Источники:** <ссылки/файлы из сессии, ресёрч-агенты, коммиты>
**Заметка:** <связки с проектами, «писать после X», приложить схему из drawings/>
```
Дедуп: если тема близка к существующей — не плодить, дописать в неё. Подтверди коротко что записал (заголовки + площадки), backlog не выводить целиком.

### `/articles list` — показать активные темы
Вывести нумерованный список тем из `articles_backlog.md` (заголовок + статус + площадка), коротко.

### `/articles draft N` — развернуть тему в скелет статьи
Взять тему N, развернуть в структуру статьи (заголовок, лид-абзац answer-first, разделы по тезисам, врезки с командами/кодом, FAQ-блок, вывод). Оптимизировать под AEO: вопрос-заголовки, прямые ответы в первых предложениях, конкретика. Черновик — в `CLAUDE/articles/<slug>.md` (папка проекта, не в память). Полную статью писать только по явному «пиши».

## Текстовый триггер (оставить)
«Статья …» / «запиши статью про …» в обычном сообщении = ручной заброс темы: оформить карточку (как выше) и дописать в `articles_backlog.md`. Это копилка тем, рождающихся по ходу работы.
