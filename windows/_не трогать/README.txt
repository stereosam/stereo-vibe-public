STEREO Vibe Lite — стартовый пакет вайбкодера для Windows
==========================================================

КАК ЗАПУСТИТЬ
1. Распакуй архив: правый клик по stereovibe-lite.zip -> «Извлечь всё».
2. В распакованной папке дважды щёлкни «Запустить Vibe.cmd».
3. Windows спросит разрешение на изменения — нажми «Да»: права нужны,
   чтобы ставить программы. Откажешься — пакет продолжит без них и предупредит.
4. Если появится синее окно «Система Windows защитила ваш компьютер» —
   нажми «Подробнее», затем «Выполнить в любом случае».
5. Отвечай на вопросы цифрами и не закрывай окно до надписи «Нажми ENTER».
   Установка может идти несколько минут — полоска внизу показывает, что всё живо.

ЧТО ДЕЛАЕТ ПАКЕТ
- проверяет место на диске и версию Windows;
- проверяет и ставит через winget: PowerShell 7, Git, Node.js LTS, Python,
  Telegram Desktop (только если согласишься);
- по твоему выбору ставит ИИ-агентов: Codex CLI, Claude Code, Gemini CLI,
  и ярлыки веб-версий ChatGPT и Gemini;
- проверяет, открываются ли ИИ-сервисы из твоей сети. Ничего не настраивает;
- в конце (если согласишься) заводит папку проекта %USERPROFILE%\stereo-vibe
  с памятью агента: CLAUDE.md (правила для агента) и папка memory\, где
  infra_status.md заполнен результатами этой проверки — что стоит, каких
  версий, куда выполнен вход, какие ИИ-сервисы открываются. Без имени
  компьютера, пользователя и IP. Существующие файлы не перезаписываются:
  при повторном запуске свежая сводка ляжет рядом как infra_status.new.md.

ПРО CHATGPT И CODEX DESKTOP
Приложения ChatGPT и Codex для Windows раздаются только через Microsoft Store,
а из России Store их не отдаёт. Поэтому пакет делает ярлык веб-версии
https://chatgpt.com (вход и подписка там те же), а для работы с кодом
предлагает Codex CLI.

ЧЕГО ПАКЕТ НЕ ДЕЛАЕТ
- не меняет настройки сети и системы;
- не ставит ИИ-программы без твоего выбора;
- не собирает личные данные.

СВЯЗЬ С ИНТЕРНЕТОМ
- программы скачивает winget из официальных источников (Microsoft, GitHub,
  сайты производителей), Gemini CLI — npm;
- если winget на компьютере нет или он сломан, пакет сначала пробует
  перерегистрировать «Установщик приложений» без скачивания. Не помогло —
  спрашивает разрешения и скачивает официальные пакеты Microsoft
  (около 300 МБ) с https://github.com/microsoft/winget-cli/releases.
  Перед установкой проверяет цифровую подпись каждого файла: она должна
  быть действительной и принадлежать Microsoft Corporation. Иначе не
  ставит ничего;
- при запуске пакет узнаёт номер свежей версии
  (https://stereosam.ru/vibe-lite/version.json). Если вышла новая — пишет
  об этом строкой со ссылкой на бота, где взять свежий архив. Сам ничего
  не скачивает и не обновляет;
- после проверки отправляет обезличенную сводку: версия пакета, случайный
  номер установки, версия Windows, статусы и версии программ из набора выше,
  открываются ли ИИ-сервисы, длительность проверки. Без имени пользователя
  и компьютера, путей, почты и ключей. Адрес: https://stereosam.ru/vibe-lite/report
  Не хочешь отправлять — запусти из командной строки:
      "Запустить Vibe.cmd" -NoReport

ТОЛЬКО ПРОВЕРКА, БЕЗ УСТАНОВКИ
В командной строке, в папке пакета:
      "Запустить Vibe.cmd" /check

ГДЕ ЛОГ
Лог и отчёт каждой проверки лежат только на этом компьютере:
      %LOCALAPPDATA%\STEREO-Vibe-Lite\logs
Путь к логу пакет пишет в конце проверки.

ЧТО ЛЕЖИТ В ЭТОЙ ПАПКЕ
check-work-tools.ps1 — сам пакет (скрипт PowerShell);
version.txt          — версия пакета;
templates\           — шаблоны памяти проекта (CLAUDE.md и memory\);
README.txt           — этот файл.
Папку не удаляй и не переноси: без неё «Запустить Vibe.cmd» не запустится.

КАК НАЧАТЬ РАБОТАТЬ ПОСЛЕ УСТАНОВКИ
Открой НОВОЕ окно PowerShell (Пуск -> «Терминал»), перейди в папку проекта
(если пакет её завёл: cd ~\stereo-vibe) и набери codex, claude или gemini.
Агент сам прочитает CLAUDE.md и memory\. При первом запуске он попросит
войти в аккаунт.
